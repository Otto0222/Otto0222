# Hi there 👋, I'm Otto

I'm a Mechanical Engineer and an M.Sc. candidate in Biomedical Engineering, with a strong interest in assistive robotics, biomechanics, and optimization-based robot control and hands on engineering. I enjoy connecting mechanical design, programming, and simulation to develop robotic systems that can make a difference in people's lives.

## 📝️ Currently working on
My master's thesis focuses on inverse kinematics for a 7-degree-of-freedom (7-DOF) assistive robotic manipulator as part of the AIRA project. I'm exploring optimization-based approaches to achieve accurate and safe robot motion while keeping computational performance suitable for real-time applications.

- Modeling and simulating robotic systems with Drake.

- Implementing differential inverse kinematics and investigating constrained and global IK approaches.

- Integrating robot control software with physical actuators using LCM and CAN communication.

- Evaluating solution accuracy, convergence, computational latency, and kinematic constraints.
